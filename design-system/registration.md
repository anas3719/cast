# Cast Registration

Preserve the existing cast/admin Tajawal typography, Arabic RTL, cyan action
color, gold secondary accents and dark surfaces. No portfolio changes.
The catalog-generated marketing/demo layout and Latin-only font suggestion
were not appropriate; focused form guidance was used instead.

- A usable form, not a landing page; two-column fields on desktop, one on mobile.
- No red required asterisks. Visible labels and inline error descriptions.
- Nationality explicitly optional. International phone/URLs isolated LTR.
- Native radios for gender/speaking/works source, file inputs for media.
- Portrait preview with stable aspect ratio; preserve the face.
- A named progress element for uploads; cancel/retry feedback stays visible.
- Private review records never enter the catalog editor's generic serializer.
- Verify keyboard focus, 390px mobile and desktop, including failed submission.
